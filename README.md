# 匿名質問箱

同じLAN（Wi-Fi）内のスマホから匿名で質問を投稿し、ランダムに1件を選んで大画面に表示する、
合宿・飲み会向けの遊び道具です。

## 仕組み

- サーバー用PC（`server.py`を実行するPC）が、質問投稿ページ・管理者ページを配信し、
  WebSocketで質問の受付とランダム選出結果の配信を行います。
- 参加者はスマホのブラウザで質問投稿ページを開き、匿名で質問を送信します。
- 管理者はスマホ（またはPC）のブラウザで管理者ページを開き、「質問開始」ボタンを押すと、
  投稿済みの質問からランダムに1件選ばれ、名前（ランダム）とセットで全参加者の画面に表示されます。
- 表示専用の別アプローチとして、pygameでフルスクリーン表示する `random_question_selector.py` も同梱しています
  （こちらはサーバーを介さず単体でも動作しますが、サーバーと併用すると結果がスマホ側にも配信されます）。

## セットアップ

```bash
pip install -r requirements.txt
```

`random_question_selector.py` を使わない場合、`pygame` は不要です（`websockets` のみで動作します）。

## 使い方

1. サーバー用PCで実行します。

   ```bash
   python server.py
   ```

   起動すると、参加者用ページ・管理者用ページのURL（`http://<サーバーのIP>:8000/...`）がログに表示されます。
2. 参加者は表示されたURL（`index.html`）をスマホのブラウザで開き、質問を投稿します。
3. 管理者は`admin.html`を開き、パスワード（`server.py`の`PASS`）を入力してログインすると、
   「質問開始」でランダムに1件表示、「終了」で表示をクリアできます。
4. サーバー用PCと参加者のスマホは同じWi-Fi（LAN）に接続している必要があります。

### pygame版（任意）

サーバー用PCで大画面に直接表示したい場合、`server.py`と並行して以下を実行できます。

```bash
python random_question_selector.py
```

Enterキーでランダムに次の質問を表示します。

## 設定

- `server.py` 冒頭の `names` （表示に使う名前リスト）やポート番号は自由に編集してください。
- `server.py` 冒頭の `PASS` は管理者ページのログインパスワードです。デフォルトのまま使わず、必ず変更してください。
- 投稿された質問は `Q/` フォルダに一時ファイルとして保存され、表示のたびに1件読み込んで削除されます。
